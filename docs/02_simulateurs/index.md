# Concevoir un simulateur

Concevoir un simulateur d'aides publiques consiste à modéliser des règles de droit administratif, puis à les présenter dans une interface compréhensible et fiable. La méthode concilie les contraintes juridiques, les besoins des usagers et les contraintes techniques.

Les pages de cette section suivent la production d'un simulateur, du texte réglementaire à la maintenance :

- [Principes de conception](./01_fondamentaux.md) : principes, valeur d'un résultat de simulation, données personnelles, accessibilité.
- [Modéliser une aide](./02_modeliser-une-aide.md) : extraire la logique d'un texte et la formaliser.
- [Simulateur multi-aide](./03_simulateur-multi-aide.md) : réunir des aides de plusieurs organismes dans un même parcours.
- [Écrire le modèle de règles](./05_passer-en-code.md) : écrire les règles avec un moteur ouvert (Publicodes, OpenFisca).
- [Tester et ajuster](./06_tester-ajuster.md) : cas types, tests automatisés et tests avec les usagers.
- [Maintenir](./07_maintenir.md) : suivre les évolutions réglementaires et tenir la documentation à jour.

Les projets existants et les outils réutilisables sont décrits dans la section [Mutualiser](/03_mutualiser/).
